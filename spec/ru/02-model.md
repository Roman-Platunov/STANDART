# Модель данных

## Карточка параметра

| Поле | Обязательно | Описание |
|------|-------------|----------|
| `sid` | да | Короткий стабильный id (8 hex) |
| `path` | да | Иерархический адрес любой глубины ≥ 2 |
| `fingerprint` | да | `sha256:` от `kind\|unit\|normalized_path` |
| `kind` | да | Природа значения |
| `unit` | да | UCUM (`-` если нет) |
| `encodings` | да | Допустимые представления |
| `sensitivity` | да | Чувствительность |
| `status` | да | `stable` \| `draft` \| `deprecated` |
| `title` | да | `{ ru, en }` |
| `aliases` | нет | `ru`, `short`, `legacy` |

## Показание (wire)

```json
{ "sid": "24d3556f", "v": 23.4, "t": 1738860000 }
```

Устройство не обязанно слать `path` или `unit`, если обе стороны используют один реестр (проверка через `registry_checksum`).

## Профиль устройства (опционально)

Список `sid`, которые устройство обязано / может отдавать. Для обмена ИИ↔устройство достаточно отдельных `sid` в показаниях.
