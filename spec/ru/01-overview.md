# STANDART — обзор

**STANDART** (Simple Typed And Named Data for Apparatus, Registry and Things) — открытый стандарт классификации типов данных для устройств.

Версия спецификации: **0.1.0**

## Зачем

Производители устройств и разработчики облачных сервисов часто придумывают собственные коды для температуры, напряжения, GPS и т.п. В результате устройства одного класса не понимают друг друга без ручного сопоставления.

STANDART задаёт **общий реестр типов**: стабильные идентификаторы, единицы (UCUM), допустимые представления (encoding) и профили устройств. Транспорт (MQTT, BLE, Modbus, HTTP) остаётся на выбор производителя.

## Три артефакта

1. **Спецификация** — человекочитаемые правила (этот каталог).
2. **Реестр** — машиночитаемые карточки типов в `registry/`.
3. **Библиотека** — сгенерированные заголовки C и типы TypeScript в `sdk/`.

## Принцип

Любое значение на устройстве описывается карточкой типа из реестра, а не «магическим числом»:

```
std:env.temperature
```

Полная ссылка на представление:

```
std:env.temperature#Cel:f32
```

## Что не входит в v0.1

- Собственный проводной или беспроводной протокол.
- Юридический статус ISO/ГОСТ.
- Отраслевые экономические или медицинские классификаторы (ISIC, HS, ICD).
