# STANDART — обзор

**STANDART** (Simple Typed And Named Data for Apparatus, Registry and Things) — открытый **общий классификатор типов данных** для обмена между **искусственным интеллектом** и **физическими устройствами**.

Версия: **0.2.0** (гибридная модель)

## Зачем

Устройство не описывает «кто я и что измеряю» длинным текстом. Оно передаёт **код из общей библиотеки**. Приёмник (ИИ, шлюз, облако) раскрывает код в полный иерархический смысл.

## Полный и урезанный код

| Вид | Поле | Пример | Где |
|-----|------|--------|-----|
| Полный | `path` | `physical.environment.temperature` | библиотека, ИИ, поиск дублей |
| Урезанный | `sid` | `24d3556f` | прошивка, обмен по сети |
| Контрольная сумма | `fingerprint` | `sha256:…` | антидубли |

Минимальный пакет:

```json
{ "sid": "24d3556f", "v": 23.4 }
```

## Три артефакта

1. **Спецификация** — `spec/`
2. **Реестр** — `registry/` (+ `manifest.json` с `registry_checksum`)
3. **SDK** — `sdk/c`, `sdk/ts`
