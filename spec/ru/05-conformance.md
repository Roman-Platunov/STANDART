# Соответствие

## L1 — Type-aware payload

Отправитель использует зарегистрированный `sid`; значение совместимо с карточкой.

## L2 — Profile (опционально)

Устройство заявляет профиль и отдаёт все `required` sid.

## L3 — Tooling

Валидатор проверяет fingerprint, уникальность path/sid/fingerprint/alias, собирает manifest.

## Добавление параметра

1. Убедиться, что path/смысл ещё нет
2. Добавить YAML → `npm run build`
3. PR: CI отклоняет дубли; похожие path — предупреждение / ревью

## Проверка

```bash
npm run build
```
